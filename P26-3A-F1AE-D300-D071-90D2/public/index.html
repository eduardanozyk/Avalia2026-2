Simulador de E-Commerce com Carteira de Créditos Fictícios

Implemente uma loja virtual completa que simula a compra e venda de itens digitais ou periféricos fictícios. Ao realizar o primeiro login via Discord OAuth2, o backend na Cloudflare cria automaticamente uma conta no D1 com um saldo inicial padrão de créditos virtuais para o estudante utilizar. O frontend em JavaScript vanilla deve gerenciar o catálogo de produtos, filtros de preço e o estado do carrinho de compras. No momento do checkout, uma Cloudflare Function valida no servidor se o saldo do usuário no banco D1 é suficiente para cobrir o somatório dos itens, deduzindo o valor, abatendo a quantidade em estoque dos produtos e gerando um recibo histórico de pedidos.
